# 演出づくりの申し送り（爆弾の比較ページ）

このファイルは、ほかのエージェント（Codex など）に、ここまでの経緯と知見を渡すためのもの。

## ゲーム
「超能力五目並べ」。HTML/CSS/JS だけのブラウザゲーム。11×11 の盤に碁石を置いて5つ並べる。碁石ごとに超能力（爆弾・回転・重力…）がある。
画面はフラットでシンプル（色を塗った面、くっきりした輪郭、影やグラデーションはほぼ使わない）。色：
- 墨 `#1f1d1a`、赤（アクセント） `#e5533d`、橙 `#ff9f1c`、黄 `#ffd23f`、盤 `#efd6a3`、盤の線 `#8a6a3a`、背景 `#f7f4ee`

## ここまでの経緯（本人の言葉）
1. 線・矢印・点で範囲を示す「図解」の演出 →「エフェクト、そういうことではないな。うごきと、例えばほのおの背景みたいな。そういうので伝えたい」「エフェクトがそのゲームの楽しさを左右するから、慎重に考えよう」
2. 属性（炎・風・渦…）ごとに、ぼかした丸い粒（Canvas の放射グラデーション）＋盤を暗くする＋閃光と衝撃波 →「エフェクトが少し安っぽいな」「まだ安っぽいな。既存の例を調査して考えようか」
3. 調べた結論：ぼかした丸い粒は「初期設定の粒」の見た目で、フラットな画面の上で浮く。これが安っぽさの一番の原因
4. 比較ページで3案を並べた。A：フラットなモーショングラフィックス風、B：手描きアニメ風（1秒12コマ、墨の輪郭、インパクトフレーム、集中線）
   - 本人：「Aが合っていると思うが、Aの方が君が下手なのか、安っぽく見える。Bの方が総合的な現時点での完成度は高いが、これからAの方が高くなる見込みがありそう。なんだろう、三角形の炎とかかな」
5. A′：三角の破片と星形（ギザギザ）の炎をやめ、円・輪・先の丸い線・なめらかな曲線だけで描き直した → 本人：**「A'、すごい良くなった！！でもまたやれそう。Aをもとにもう少し練りたい」**

## 守ること（調べて分かった原則）
- 予兆 → 衝撃 → 余韻 の3つの段階で組む。強さの多くは、当たる前の予兆で決まる
- 形は太く、輪郭はくっきり。ぼかし・グラデーション・光の足し合わせは使わない（フラットな画面と合わない）
- 三角・星形・ギザギザなど、クリップアートの定番の図形は使わない（安っぽく見えた）。円・輪・先の丸い線・しずく形・なめらかな曲線で描く
- 消えるときは、薄くするより縮めて消す
- 層を重ねる：石の動き・盤の揺れ・まわりの石の反応・炎・粒・煙。どれか1つで見せない（Balatro の考え方）
- 少し行き過ぎてから戻る（オーバーシュート）、部分ごとに少しずつ遅らせる（オーバーラップ）
- 色は少なく。黒い線は強すぎて騒がしかったので、線は属性の色にした
- 演出の役目は、何が起きたかを楽しく伝えること。粒を増やせば良くなるわけではない

## A′ のいまの作り（tools/fx-compare.html の drawA2）
- 予兆：爆弾の石が落ちる → つぶれて着いて跳ねる → ふくらみながら震え、まわりに細い輪が脈打つ。届く範囲（3×3）に角の丸い点線の枠
- 止め：白い円がぽんと出る（0.06秒）
- 衝撃：芯が白→黄→橙と段で色を変えながら縮む／輪が広がりながら8つの弧に割れる／先の丸い線が伸びてから根元から消える／しずく形の炎を赤・橙・黄の3層で少しずつ遅らせて重ねる／小さな丸が飛び、さらに小さな丸が続く
- まわりの石：ふくらんでから、小さな丸3つに割れて消える。離れた石は押されて揺れる
- 余韻：丸の煙がふくらんで昇り、縮んで消える。焦げ跡が丸く広がり、ゆっくり縮む
- 参考の静止画：tools/ref/a2-*.png（時刻 0.8〜1.5 秒）

## 比較ページの仕組み
- `tools/fx-compare.html`。時刻 t（0〜2.8 秒をくり返す）を受け取って1枚の絵を描く関数を、毎フレーム呼ぶ。同じ t なら同じ絵になる（決まった乱数 `rng(seed)` を使う）
- 使える定数と関数（ページの中で定義済み）
  - `N`（=7、盤のマスの数）、`INK` `ACC` `ORANGE` `YELLOW` `BOARD` `LINE`、`LOOP`（2.8）、`T_DROP`（0.45、落ち始め）、`T_LAND`（0.6、着地）、`T_BOOM`（0.98、爆発。その前の0.06秒が止め）
  - `PRE`：先に置いてある石 `[x, y, 色('b'|'w'), 爆発で消えるか(1|0)]`。爆弾は (3,3) に置かれる
  - `clamp` `lerp` `easeOut` `easeIn` `backOut` `rng(seed)`、`drawBoard(c, w, ox, oy, cell)`、`stone(c, x, y, r, color)`、`bombIcon(c, x, y, r)`、`drop(c, x, y, r, h, ang)`（しずく形）、`capsule(c, x, y, a, r0, r1, t0, t1, width, col)`（先の丸い線の一部）
  - 盤の座標の計算は drawA2 と同じにする：`cell = w / (N + 0.6)`、`ox = oy = (w - cell * (N - 1)) / 2`、`P(i, j) = [ox + i * cell, oy + j * cell]`、石の半径 `R = cell * 0.42`
