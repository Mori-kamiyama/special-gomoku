# 超能力五目並べ

碁石に超能力がある五目並べ。超能力を駆使して五目並べろ！

1台を2人で囲んで遊ぶ「2人で対戦」、CPU（白）と遊ぶ「CPUと対戦」、知らない人と当たる「オンライン対戦」がある。

- 碁石は1人12個。ただの石が6個と、最初に取り合った超能力の碁石が6個。取るのも置くのも黒から
- 5つ並べるほか、旗と結束による特殊勝利がある
- 超能力の碁石は28種類。取り合いでは毎回3つが出て、1つ取る。黒と白が交互に6回ずつ
- 手札3つから1つ選んで置く。5つ並べたら勝ち。2人とも使い切って揃わなければ引き分け

## 超能力
| 名前 | 効果 |
|---|---|
| ジョーカー | 白にも黒にもなる。相手の列にも入る |
| 押し出し | まわりの石を1マス外へ押す。盤から落ちた石は消える |
| 吸い込み | 2マス先の石を1マス手前まで吸い寄せる |
| 爆弾 | まわりの石を全部消す |
| 横爆弾 | 左右2マスずつの石を消す |
| 縦爆弾 | 上下2マスずつの石を消す |
| ななめ爆弾 | ななめ4方向に2マスずつの石を消す |
| 旗 | 上下左右の4マスが全部自分の石になったら勝ち |
| 結束 | この碁石を含む2×2の正方形が自分の石でそろったら勝ち |
| 増殖 | 盤にある間、自分の番が2回来るたびに、隣の空きマスに石が1つ増える |
| オセロ | 相手の石をちょうど1個はさんだら、その石を自分の色にする |
| 囲碁 | 盤にある間、隣の相手の石が囲まれて逃げ場をなくしたら取る |
| 連続 | もう1回置ける |
| 重力 | いつでも下へ落ちる。石か盤の端で止まる |
| 反重力 | いつでも上へ昇る。石か盤の端で止まる |
| 回転 | まわりの8マスを、時計回りに1つずらす |
| 逆回転 | まわりの8マスを、反時計回りに1つずらす |
| 分身 | 盤の真ん中をはさんだ反対側にも、自分の石が1つ増える |
| 左右分身 | 左右に折り返した位置にも、自分の石が1つ増える |
| 上下分身 | 上下に折り返した位置にも、自分の石が1つ増える |
| 石垣 | 上下左右の空きマスに、誰のものでもない石を置く |
| 乗っ取り | 相手の石の上に置ける。下の石は消える |
| 封印 | 相手は次の番、超能力が使えない |
| おじゃま | まわり8マスの碁石の超能力を消して、ただの石にする |
| スパイ | 相手の色で置く。この石を含む列が揃ったら、こっちの勝ち |
| 地雷 | まわり8マスに相手が石を置いたら、その石と一緒に消える |
| 重し | 押し出し・吸い込み・回転で動かされない |
| 盾 | 爆弾・囲碁・地雷・乗っ取りで消されない |

超能力を足すときは、`script.js` の `ABILITIES` に1件、`ICONS` にアイコンを1件足す。

## 1手の中の順番
能力の効果 → 重力・反重力で落ちる → 囲碁と地雷で取る →（何も変わらなくなるまで、重力と囲碁をくり返す）→ 勝ち判定

## 演出
`fx.js`。碁石ごとに属性（炎・風・渦・重力・大地・水面・呪い・影・雷・植物・光・反転）を決め、置いた瞬間に、その属性の粒を Canvas で出す。盤を一瞬その色で暗くし、白い閃光と衝撃波のあとに粒が広がる。取り合いのカードでは、マウスを乗せると属性の背景が動き、5×5 のお試しの盤で動きを実演する。

## 効果音
`sound.js`。音のファイルは使わず、Web Audio でその場でつくる。右上のボタンで消せる。

## オンライン対戦
`net.js`。[Trystero](https://github.com/dmotz/trystero)（サーバーなしの WebRTC）でつなぐ。相手さがしは Nostr の公開ネットワークを使い、直接つながらない回線のために無料の TURN（Open Relay）を保険にしている。サーバーを持たないので、静的なページ（GitHub Pages など）に置くだけで動く。
- 相手さがし：ロビーにいる人を ID の順に並べ、自分より ID が大きい空いている人だけを誘う。決まったら2人だけの部屋に移る
- 同じ流れにする：誘った側（ホスト）が乱数の種と色を決めて送る。あとは「どの碁石を取ったか」「どの碁石をどこに置いたか」だけを送り、両方で同じ計算をする
- 通信のつなぎ方を替えるときは `net.js` だけを書き換える

## CPU
`ai.js` が CPU の頭脳。ゲームの CPU 対戦と、バランスの計測の両方で使う。
- 打つ手：minimax で2手先まで読む。自分の手を全部試し、良さそうな上位8手について、相手のいちばん良い返し手まで読んで比べる。手札は公開なので、相手の次の手札も分かる
- 取り合い：計測で勝率が高かった碁石から取る（`PICK_VALUE`）

## バランスの計測
`node tools/balance.mjs 3000 --depth 2` で、CPU 同士を3000局対戦させ、能力ごとの勝率を `tools/balance-report.md` に書き出す。コアの数だけ並列に動く（mameta の32スレッドで49秒）。測れるのは CPU が使ったときの強さなので、最後は人が遊んで確かめる。

HTML / CSS / JavaScript だけで作っている。`index.html` をブラウザで開けば動く。
